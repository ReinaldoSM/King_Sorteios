# 🎲 Sorteador de Números

Projeto desenvolvido com **HTML**, **CSS** e **JavaScript**, permitindo realizar sorteios de números aleatórios de forma simples, rápida e intuitiva.

## 🚀 Funcionalidades

- Sorteio de números aleatórios.
- Definição do número inicial e final do sorteio.
- Validação para impedir que o número inicial seja maior que o número final.
- Interface simples, moderna e responsiva.
- Geração instantânea do resultado.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, pude praticar conceitos importantes como:

- Manipulação do DOM;
- Eventos em JavaScript;
- Condicionais (`if/else`);
- Funções;
- Geração de números aleatórios (`Math.random()`);
- Validação de formulários;
- Organização e estruturação de código.
